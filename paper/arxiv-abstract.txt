We measure what a coding agent spends to solve the same tasks in 18 programming languages and three front-end frameworks, with one isolated Claude Opus 5.5 agent per case and hidden tests checked live. Across 294 runs the language barely changed correctness but changed the cost: Python was the cheapest and Assembly cost 4.8x as much, and cost to write and speed of the code rank against each other (Spearman rho = 0.57). Repeating every round with one researched SKILL.md per language, 27 of 31 languages cost more beyond run-to-run noise and 0 cost less (median run +38%), mostly context written to the prompt cache; the overhead shrinks on longer tasks, and only for Zig, whose API changed after the model's training, did the skill replace work. Porting working programs from our three slowest languages to five common rewrite targets cost more than writing them from scratch in 14 of 14 pairs (+37% to +91%), with every port correct and Zig ports a median 5.0x faster than their source. A team of agents (a lead, three workers in parallel git worktrees and an integrator) built a three-part program slower than one agent in 5 of 5 languages tried (0.50-0.78x the solo speed) and cost +113% to +193% more. Data, code and every solution are public.
