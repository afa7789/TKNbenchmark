# Sources

## Official documentation and release notes
- https://ziglang.org/download/0.16.0/release-notes.html: 0.16 breaking changes. Covers the `std.Io` interface (async, concurrent, Group, cancelation), "juicy main" `std.process.Init`, the `std.fs` → `std.Io.Dir`/`File` renames, sync primitives moved to `Io`, removal of `Thread.Pool`, time/sleep/random via `io`, process spawn/run, `std.Io.net`, `@Type` split into `@Int`/`@Struct`/…, deprecation of `@cImport` in favor of `addTranslateC`, unmanaged hash map renames, `PriorityQueue` renames, zon `fingerprint`, `zig-pkg/`, `--test-timeout`, `--error-style`, and the new language rules (vector indexing, expired-local address, float coercion, `@floor` to int).
- https://ziglang.org/download/0.15.1/release-notes.html: "Writergate" (non-generic `std.Io.Reader`/`Writer` with caller-owned buffers and `flush`), `ArrayList` becoming unmanaged, removal of `usingnamespace` and async/await, the `{f}` format specifier and new `format` signature, `BoundedArray` → `initBuffer` + `*Bounded`, removal of `root_source_file` from `addExecutable` in favor of `root_module`.
- https://ziglang.org/documentation/0.16.0/: language reference Style Guide (TitleCase types and type functions, camelCase functions, snake_case variables, fields, and namespaces, file naming, avoiding redundant names, 4-space indentation and trailing commas, `unreachable` semantics per build mode).

## Installed toolchain (Zig 0.16.0, Homebrew, macOS arm64), verified locally
- `lib/zig/init/` (`zig init` template): canonical `build.zig` (module + exe + tests), `build.zig.zon` fields, and the `main(init: std.process.Init)` stdout-writer pattern.
- `lib/zig/std/process.zig`, `process/Args.zig`, `process/Environ.zig`, `process/Child.zig`, `start.zig`: `Init` fields, how `gpa`/arena/`Io.Threaded` are chosen, `run`/`spawn`/`fatal`/`currentPathAlloc`.
- `lib/zig/std/Io.zig`, `Io/Dir.zig`, `Io/File.zig`, `Io/Reader.zig`, `Io/Writer.zig`, `Io/net.zig`, `Io/Threaded.zig`: exact signatures for files, dirs, readers/writers, `Allocating`, `Timestamp`/`Clock`/`Duration`, `Future`/`Group`/`Mutex`, and networking.
- `lib/zig/std/heap.zig`, `array_list.zig`, `json/static.zig`, `fmt.zig`, `Build.zig`, `Build/Module.zig`, `Build/Step/TranslateC.zig`: allocator names, `ArrayList` methods (`print`, `*Bounded`), JSON parse options, build APIs (`addLibrary`, `addTranslateC`, `addOptions`, `dependency`).
- Scratch builds with `zig test`, `zig run`, and `zig build`: compiled every snippet in SKILL.md and recorded the exact compiler errors for stale idioms (`std.fs.cwd`, `GeneralPurposeAllocator`, `ArrayList.init`, `std.io`, `@Type`, `std.Thread.Mutex`, `std.crypto.random`, and others). Also confirmed that copying `.interface` segfaults, that `{}` silently ignores `format` methods, that `{D}` was removed, that an invented zon fingerprint is rejected, and that cross-compiling to `x86_64-linux-musl` works.

## Community guidance
- https://ziggit.dev/t/file-i-o-basics-0-16/14968: 0.16 file I/O patterns and pitfalls: never copy `.interface`, flush, `StreamTooLong` for lines longer than the buffer, unwrap `ReadFailed`/`WriteFailed` via `.err`, propagate `error.Canceled`, `readFileAlloc` with a limit.
- https://ziggit.dev/t/is-having-a-centralized-stdout-stderr-location-no-longer-recommended/14936: consensus to wire up `io` and writers in `main` and pass `*std.Io.Writer`/`io` down instead of using globals, especially in library code.
- https://www.skills.sh/vercel-labs/native/zig: a 0.16 agent skill organized by compile error. Its two core rules ("I/O takes `std.Io` from `init.io`/`std.testing.io`/`Io.Threaded`" and "containers start `.empty`, with the allocator in every call") and its advice to run both `zig build` and `zig build test` because analysis is lazy.
- https://claudskills.com/skills/zig-0-16/SKILL.md: the zigcc `zig-0.16` agent skill. Its 0.15→0.16 porting checklist (`@Type` builtins, `addTranslateC`, zon fingerprint, threading `io`, `std.Io.net`, error renames, test timeouts) matched the release notes and helped decide which items to cover.
- https://www.skills.sh/zigcc/skills/zig-0.16 and https://skillsmp.com/creators/plutowang/agent.files/core-skills-zig: listings of other published Zig 0.16 agent skills, checked for consensus on juicy main, `Io` threading, and `@cImport` removal.
